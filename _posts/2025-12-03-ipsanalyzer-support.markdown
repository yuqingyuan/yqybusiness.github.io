# IpsAnalyzer Support

Welcome to the IpsAnalyzer support page. We're here to help you get the most out of your iOS crash file analysis experience.

## Getting Started

IpsAnalyzer is an iOS crash file analysis tool that helps you analyze and debug iOS crash reports (.crash files). Here are some common questions and answers to help you get started.

## Frequently Asked Questions

### How do I import crash files?

You can import iOS crash files (.crash files) into IpsAnalyzer by:
1. Opening the app
2. Tapping the "Import" or "+" button
3. Selecting the crash file from your device's file system or other apps

### What file formats are supported?

IpsAnalyzer supports standard iOS crash file formats (.crash files) and dSYM files for symbolication.

### How do I symbolicate a crash report?

To symbolicate a crash report:
1. Import your crash file
2. If you have the corresponding dSYM file, import it as well
3. The app will automatically attempt to symbolicate the stack traces using the dSYM file

### Can I export analysis results?

Yes, you can export your analysis results in various formats for sharing with your development team or for documentation purposes.

### Where are crash files stored?

All crash files and analysis data are stored locally on your device. They are not uploaded to external servers unless you explicitly choose to sync or backup your data.

## Troubleshooting

### The app cannot read my crash file

- Ensure the file is a valid iOS crash file (.crash format)
- Check that you have granted the app necessary file access permissions
- Try importing the file again

### Symbolication is not working

- Verify that you have the correct dSYM file matching your app's build
- Ensure the dSYM file is not corrupted
- Check that the architecture matches (arm64, armv7, etc.)

### The app crashes or freezes

- Try restarting the app
- Ensure you have sufficient storage space on your device
- If the problem persists, try uninstalling and reinstalling the app
